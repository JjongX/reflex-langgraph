CLI
***

This page describes the command line interface (CLI) of reflex-langgraph.

For getting help on the CLI:

.. code-block:: text

   $ reflex-langgraph -h

   usage: reflex-langgraph [-h] [-v] COMMAND ...

   positional arguments:
     COMMAND
       init-env     Create a .env file from a .env.example file.
       ui           Run the chat UI for a running backend.

   options:
     -h, --help     Show this help message and exit.
     -v, --version  Show the version number and exit.

For getting help on a specific command (e.g. ui):

.. code-block:: text

   $ reflex-langgraph ui -h

init-env
========

.. code-block:: text

   $ reflex-langgraph init-env -h

   usage: reflex-langgraph init-env [-h] [--example PATH] [--out PATH]

   Create a .env file from a .env.example file.

   The new file is readable by you only (mode 600), since it is where API keys go,
   and an existing file is never overwritten. Fill in the values left empty.

   Optional arguments:
     -h, --help      Show this help message and exit.
     --example PATH  Template to copy (default: .env.example).
     --out PATH      File to create (default: .env).

   [Example] To create ./.env from ./.env.example:
     $ reflex-langgraph init-env

   [Example] To create the file somewhere else:
     $ reflex-langgraph init-env \
     --example backend/.env.example \
     --out backend/.env

ui
==

.. code-block:: text

   $ reflex-langgraph ui -h

   usage: reflex-langgraph ui [-h] [--env-file PATH] [--no-env-file] [--api URL]
                              [--title TEXT] [--subtitle TEXT]
                              [--placeholder TEXT] [--greeting TEXT]
                              [--jobs {auto,on,off}] [--accent COLOR]
                              [--port INT] [--backend-port INT]
                              [--backend-host HOST] [--public-url URL]
                              [--single-port] [--prod] [--workdir PATH]

   Run the chat UI for a running backend.

   The UI needs no frontend code: the page is built from the backend's /health
   (its title, and whether it has jobs) and runs as a small generated Reflex
   project. It has no login, so anyone who can open it can use it: keep it
   private (an SSH tunnel, or a firewall open to known addresses only).

   Each setting comes from its flag, else from its environment variable
   (RLG_API_URL, RLG_UI_*), else from its default. The variables are also read
   from ./.env, but only those names: the backend's API keys in the same file
   never reach the UI process.

   Optional arguments:
     -h, --help            Show this help message and exit.
     --env-file PATH       File to read RLG_API_URL and RLG_UI_* from
                           (default: ./.env, if it exists).
     --no-env-file         Do not read a .env file.
     --api URL             Backend URL, as seen from this machine
                           (default: $RLG_API_URL, or http://localhost:8100).
     --title TEXT          Page title (default: $RLG_UI_TITLE, or the
                           backend's title).
     --subtitle TEXT       Text under the title (default: $RLG_UI_SUBTITLE).
     --placeholder TEXT    Hint text in the message box
                           (default: $RLG_UI_PLACEHOLDER).
     --greeting TEXT       Shown above the message box in an empty chat
                           (default: $RLG_UI_GREETING, or "What can I help
                           with?").
     --jobs {auto,on,off}  Show the jobs panel (default: auto, which shows it
                           when the backend has jobs).
     --accent COLOR        Radix accent colour (default: $RLG_UI_ACCENT, or
                           indigo).
     --port INT            Frontend port (default: $RLG_UI_PORT, or 3000).
     --backend-port INT    Port of Reflex's own backend
                           (default: $RLG_UI_BACKEND_PORT, or 8000).
     --backend-host HOST   Interface Reflex's backend binds to.
     --public-url URL      URL the browser uses to reach Reflex's backend,
                           when it is not localhost, e.g.
                           http://<public-ip>:8000 (default: $RLG_UI_PUBLIC_URL).
     --single-port         Only check that --port and --backend-port match:
                           a production build always serves the page and
                           Reflex's backend on one port.
     --prod                Run a production build instead of the dev server:
                           use it to try or show the UI. Give --port and
                           --backend-port the same number.
     --workdir PATH        Directory of the generated Reflex project
                           (default: ~/.cache/reflex-langgraph/ui).

   [Example] To run the UI for a backend on this machine, as the production
   build (to try it or show it; the page loads in a fraction of a second):
     $ reflex-langgraph ui --prod --port 3000 --backend-port 3000

   [Example] To run it on Reflex's development server, while changing UI code
   (the first page load takes seconds):
     $ reflex-langgraph ui

   [Example] To run it for another backend, with its own title:
     $ reflex-langgraph ui \
     --api http://10.0.0.5:8100 \
     --title "Lab assistant"
